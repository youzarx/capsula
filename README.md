# Capsula

> **Visuals, generated by code.**  
> Dynamic, responsive, and secure SVG banners and headers for your GitHub profile and project repositories.

Capsula is a high-performance SVG header generator designed for developers who want polished, theme-reactive, and customizable banners for their GitHub Profile READMEs, organization pages, and repository documentation. Built with a dark-obsidian and electric-blue visual aesthetic, Capsula renders lightweight, pure SVG vector graphics dynamically via URL parameters or through its interactive generator web studio.

Capsula is an enhanced and security-hardened evolution of [`capsule-render`](https://github.com/kyechan99/capsule-render) by kyechan99, developed for the **youzarx** ecosystem.

## Features

- **18 Distinct Render Models:** 13 static geometric shapes (`wave`, `rect`, `slice`, `cylinder`, `diagonal`, `dots`, `curve`, etc.) and 5 kinetic animated models (`waving`, `venom`, `pulse`, `checkered`, `blur`).
- **15 Integrated Designer Themes:** Full support for `github-dark`, `tokyonight-storm`, `catppuccin-mocha`, `nord-dark`, `synthwave84`, `radical`, `onedark`, and more.
- **Directional Gradient Engine:** Configure linear gradient rotations across $0^\circ$ to $360^\circ$ (`gradientAngle`) with multi-stop color support.
- **Dynamic Text & Multiline Layouts:** Primary titles and subtitles with multiline line-breaking (`-nl-`), independent XY alignments, font rotation, and custom font stacks.
- **Interactive Web Generator Studio:** Real-time preview panel with instant client-side SVG rendering, multi-canvas backdrops (Obsidian, GitHub Dark, Light, Grid), and one-click Markdown/HTML snippet export.
- **Deterministic & Memory-Safe:** Fully refactored renderer guarantees pure coordinate calculations across multiple render cycles without state pollution.
- **Hardened Security Boundary:** Automatic XML entity escaping, CSS `<style>` breakout prevention, and strict parameter boundary checks.

## Quick Start

### Markdown Embedding

Insert dynamic SVG headers directly into your GitHub Profile `README.md`:

```markdown
<!-- Default Wave Banner -->
![Capsula Header](https://capsula-beta.vercel.app/api?type=wave&text=Welcome%20to%20my%20Profile)

<!-- Electric Obsidian Dark Theme with Subtitle -->
![Capsula Header](https://capsula-beta.vercel.app/api?type=waving&theme=github-dark&text=youzarx&desc=Full-Stack%20Architect&fontSize=64&descSize=22)

<!-- Angled Linear Gradient with Custom Width -->
![Capsula Header](https://capsula-beta.vercel.app/api?type=diagonal&width=1000&height=280&color=gradient&gradientAngle=90&text=Project%20Overview)
```

### HTML Embedding

For centered alignment or explicit sizing in GitHub or website documentation:

```html
<p align="center">
  <img 
    src="https://capsula-beta.vercel.app/api?type=waving&theme=tokyonight-storm&text=Capsula&desc=Visuals,%20generated%20by%20code.&fontAlignY=46&descAlignY=64" 
    alt="Capsula Header" 
    width="100%" 
  />
</p>
```

> **Note on Endpoints:** Replace `https://<your-deployed-domain>/api` with your actual deployed host URL. Capsula does not operate a public third-party SaaS proxy.

### Color Modes & Gradients (`color`, `gradientAngle`)

- **Presets:** `color=gradient` (automatic dynamic gradient), `color=auto` (palette auto-match), `color=timeGradient` / `color=timeAuto` (time-of-day chromatic shift).
- **Custom Solid Hex:** `color=090a0f` or `color=1e90ff`.
- **Custom Multi-Stop Gradient:** Specify percentage stops separated by colons and commas:  
  `color=0:0052D4,50:4364F7,100:6FB1FC`
- **Gradient Angle (`gradientAngle`):** Rotate linear gradient angle from `0` to `360` degrees (e.g. `0` = Left-to-Right, `90` = Top-to-Bottom, `180` = Right-to-Left, `270` = Bottom-to-Top). Default is `0`.

### Typography & Subtitles (`text`, `desc`)

- **Multiline Text:** Use `-nl-` delimiter inside `text` or `desc` to create line breaks:  
  `text=Hello-nl-World&desc=First-nl-Second`
- **Positioning:** Adjust X and Y alignment percentages using `fontAlign` / `fontAlignY` for title, and `descAlign` / `descAlignY` for subtitle. Default is centered (`50`).
- **Text Badging (`textBg`):** Set `textBg=true` and optional `textBgColor=161b22` to render a rounded capsule pill behind title text.
- **Rotation (`rotate`):** Tilt text between `-360` and `360` degrees.

### Animations (`animation`)

Subtle CSS keyframe animations applied to text elements:
- `fadeIn` *(default)*: Smooth opacity fade on load.
- `scaleIn`: Zoom scale expansion.
- `blink`: Subtle entrance blink.
- `blinking`: Continuous stepped blink.
- `twinkling`: Ambient pulsing opacity loop.

## Local Development & Testing

### Prerequisites

- Node.js 18+ (Node 20+ recommended)
- `npm` (Lockfile Version 3)

### Installation

Clone the repository and install dependencies cleanly:

```bash
git clone https://github.com/youzarx/Capsula.git
cd Capsula
npm ci
```

### Development Server

Run the Vite development server for the interactive studio:

```bash
npm run dev
```

To run both the Vite frontend studio and the local serverless `/api` routes concurrently using the Vercel CLI:

```bash
npm start
# (Runs `vercel dev`)
```

### Type Checking & Testing

Capsula includes a comprehensive regression and security test suite:

```bash
# Run TypeScript compilation checks
npm run typecheck

# Run unit and security regression test suites
npm test

# Run tests in watch mode
npm run test:watch
```

### Production Build

```bash
npm run build
```
Compiles TypeScript models and builds production bundles into `dist/`.

## Deployment Guide

### Native Deployment: Vercel (Tested)

Capsula is architected out-of-the-box for deployment on **Vercel**:
1. Connect your GitHub repository fork `https://github.com/<your-username>/Capsula` to Vercel.
2. Vercel automatically detects Vite in the root directory.
3. Serverless API routes in `/api/index.ts` and `/api/options.ts` are automatically mounted under `/api` and `/api/options`.
4. The client studio is built via `npm run build` into `dist/`.

### Custom Node.js / Docker Host (Alternative)

To deploy on traditional Node.js platforms (e.g. Railway, Render, Fly.io, or Docker), wrap `api/index.ts` with an Express or Fastify entrypoint to mount the endpoints and serve `dist/` static files.

## Security & Validation

Capsula implements strict defense-in-depth sanitization:
1. **XML/SVG Injection Prevention:** User inputs for `text` and `desc` are parsed through an entity escape parser. Pre-existing entities (`&amp;`, `&#39;`) are preserved without double-escaping. Hostile payload tags (`<script>`, `<foreignObject>`) cannot execute.
2. **CSS Font-Family Sanitization:** `fontFamily` parameters are strictly checked against a whitelist regex (`/^[a-zA-Z0-9\s,._\-'"@]+$/`) to prevent breakout from SVG `<style>` tags.
3. **Bounded Numeric Allocation:** Canvas bounds ($200 \le \text{width} \le 2500$, $1 \le \text{height} \le 2000$) prevent memory exhaustion or server Denial-of-Service attacks.

## Troubleshooting

- **Image does not load in GitHub README:**
  - Verify that the URL is public and accessible over HTTPS. GitHub Camo proxy rejects non-HTTPS and `localhost` URLs.
  - Verify all query parameters are valid. Invalid parameter values return HTTP 400.
- **Localhost snippet exported:**
  - When running locally, configure `VITE_PUBLIC_API_URL` or export snippets once deployed on your production domain.
- **Font alignment shifted:**
  - Different operating systems render system fonts with slight typographical variance. Adjust `fontAlignY` and `descAlignY` by $\pm 2$–$5\%$ for custom typography.
